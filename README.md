# Бот «Новости Вьетнама для своих»

Каждые 20 минут бот читает вьетнамские новостные сайты, отбирает то, что интересно русским во Вьетнаме
(криминал, туристы, русские, визы, законы, погода, курьёзы), переводит на живой русский с лёгкой иронией,
сам себя проверяет на выдуманные факты и публикует в Telegram-канал.

## Как устроен конвейер

1. **Сбор** — RSS VnExpress, Thanh Niên, Tuổi Trẻ, Dân Trí, VnExpress International + страницы рубрик
   Báo Khánh Hòa (местная газета Нячанга). Список в `bot/sources.py`.
2. **Предфильтр** (бесплатно) — ключевые слова: иностранцы, русские, Нячанг и курортные города, визы,
   криминал, запреты, погода. Пленумы, отчёты министерств и сельское хозяйство отсекаются сразу. `bot/filters.py`.
3. **Оценка 0–10** быстрой моделью: насколько это обсудят в русском чате Нячанга + поиск дублей
   (одна история часто выходит на трёх сайтах).
4. **Рерайт** сильной моделью: заголовок, 300–700 знаков, практический вывод «👉», хэштеги, ссылка на источник.
5. **Фактчек** — вторая модель сверяет пост со статьёй. Нашла выдуманное — пост переписывается;
   если и после этого сомневается — пост уходит тебе на ручную проверку даже в авто-режиме.
6. **Публикация по расписанию** — не чаще раза в 45 минут, не больше 10 в день, ночью тишина,
   первым уходит самое интересное. Всё настраивается в `.env`.

Характер канала (что интересно, тон, запреты на шутки) — в `bot/prompts.py`. Правь как хочешь.

## Запуск

**Проще всего — установщик для Mac:** скачай `install-vn-news-bot.sh` и выполни в Терминале

```bash
bash ~/Downloads/install-vn-news-bot.sh
```

Он сам распакует бота в `~/vn-news-bot`, скачает программу GitHub, проведёт через вход в GitHub,
создание бота и канала в Telegram, получение ключа нейросети, загрузит всё на GitHub, сохранит
ключи в секреты и запустит бота. Дальше бот работает на серверах GitHub каждые 20 минут.

Управление после установки: `~/vn-news-bot/botctl.sh` (запуск, журнал, стоп/старт, режим, правка тона).

**Вручную на своём сервере:**

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env && nano .env     # впиши ключи
python -m bot.main --test-url https://vnexpress.net/...   # как бот перепишет одну статью
python -m bot.main                    # боевой режим (или systemd: deploy/vn-news-bot.service)
```

Нейросеть выбирается переменной `LLM_PROVIDER`: `gemini` (бесплатный тариф, по умолчанию),
`openrouter` (один ключ ко многим моделям, оплата картой или криптой), `anthropic` (Claude напрямую).

## Режимы

- `MODE=moderate` (по умолчанию, советую первые 1–2 недели) — каждый готовый пост приходит тебе в личку
  с кнопками **✅ В очередь / 🚀 Сейчас / ❌ Мимо**. Так ты увидишь, что бот выбирает, и подкрутишь промпты.
- `MODE=auto` — сразу в очередь канала. Сомнительные по фактчеку всё равно идут к тебе.

## Что важно знать

- **Форумы.** Вьетнамские форумы (voz.vn) и группы в Facebook закрыты от ботов и требуют входа —
  парсить их ненадёжно и против их правил. Новости сайтов — тот же поток, но проверенный редакцией.
  Если найдёшь открытый источник с RSS — просто добавь строку в `bot/sources.py`.
- **Ленты** с `verified=True` проверены 15.10.2026. Если какая-то лента начнёт отдавать 0 записей,
  в логе будет предупреждение.
- **Курс валют**: впиши в `RATES` строкой (например `1 000 донгов ≈ … ₽`), бот будет пересчитывать суммы.
  Пусто — суммы останутся в донгах.
- **Имена**: бот сокращает имена частных лиц до инициалов и не шутит над погибшими и жертвами насилия —
  это защищает канал от жалоб и блокировок.
- База `news.db` хранит всё, что бот видел: можно посмотреть, что и почему он отсеял
  (`status`, `score`, `note`).
